# HDR Lab Light v0.2.0 — Cleanup

This release improves development, validation, and maintenance without changing the visual test flow or video patterns.

- Added a Windows PowerShell validation command with automatic JDK/SDK discovery, saved logs, optional pattern verification, and a release APK size check.
- Added pull-request and main-branch CI for unit tests, lint, release compilation, decoded video pattern verification, and the APK size budget.
- Fixed manual release tag selection and require the existing tag to match the app version before publishing.
- Centralised report version metadata on the version generated by Gradle and removed the unused Media3 Transformer dependency.
- Added concise agent instructions, developer and architecture guides, and consistent editor/line-ending settings.

The release signing identity is preserved. The previously exposed signing key and report-delivery reliability still require dedicated follow-up work.
