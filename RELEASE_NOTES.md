# OLED Tester v0.3.0-beta.2

Second OLED suite preview for `dev.hdrlab.light`.

- Fullscreen brightness slider (1%–100%) for Quick Test and all Canvas suites.
- Nine burn-in/ageing slides: red, green, blue, white, 50% grey, 20% grey, cyan, magenta and yellow.
- SDR/HDR selection via window colour mode, API 35 HDR headroom and SDR/PQ video switching in the step ladder.
- Optional burn-in/image-retention report field (`oledBurnIn`).
- Fullscreen cleanup restores brightness, refresh overrides and colour mode on exit, pause, stop and Back.
